## About Me

I am **Temitope**. I focus on **defensive security, threat detection and incident response**. This repository documents hands-on work in alert triage, log analysis, SIEM monitoring, IOC investigation and network fundamentals.

Every investigation answers four questions: **What happened? How did it happen? What evidence supports it? How does the detection improve?**

My background is in analytical chemistry and content writing. Chemistry taught me to test every claim against evidence. Writing taught me to explain findings in plain language. I use both in every write-up.
